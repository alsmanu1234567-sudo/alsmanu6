# 🤖 WhatsApp Bot Pro

**بوت لإدارة واتساب عبر تيليجرام، مع لوحة ويب عربية للمجموعات والردود والأدوات.**

> مشروع مستقل غير تابع لـ WhatsApp أو Telegram. قد تتغير واجهات الخدمات وحدودها، وقد تتعطل بعض الوظائف أو تتطلب صلاحيات إضافية. استخدمه بموافقة أصحاب الحسابات والمجموعات ووفق شروط الخدمات.

## ✨ المميزات

- **الربط والإدارة:** ربط رقم واتساب عبر QR أو رمز، وإدارة الأرقام المتاحة، وإيقاف معالجة الرسائل وتشغيلها. التنظيف يتجاهل الرسائل القديمة ويفرّغ المهام المنتظرة دون فصل الجلسة.
- **لوحة الويب:** واجهة عربية لإدارة الإعدادات والمجموعات والردود والرسائل والحالات، ولوحة مطور منفصلة.
- **المجموعات:** إعدادات الروابط، رسائل الترحيب والوداع، إدارة الأعضاء، وفلتر كلمات عربية وإنجليزية مع كلمات إضافية قابلة للتخصيص. حذف رسائل الأعضاء يتطلب صلاحية مشرف.
- **الردود التلقائية:** ردود نصية ووسائط وتفاعلات وبطاقات، مع إعدادات اختيارية للذكاء الاصطناعي.
- **الألعاب:** خيارات في عالم المجموعات، تشمل XO ولودو والمبارزة والسلوت. توفر كل لعبة وطريقة عملها قد يختلفان حسب إعدادات المجموعة.
- **الحالات:** نشر نص وصورة وفيديو ومحاولة الإرسال إلى جهات الاتصال المتاحة للبوت، دون خفض جودة الوسائط في البوت. قد تكون جهات الاتصال المتزامنة ناقصة، وقد يعالج واتساب أو تيليجرام الوسائط أو يفرضان قيوداً. حد الرفع الحالي 20 ميغابايت، ولا يضمن قبول فيديو بأي مدة. بعض ميزات الجدولة والتلقائي غير مكتملة.
- **أدوات إضافية:** البحث والوسائط وإزالة خلفية الصور عبر Poof حسب الإعداد والخطة المتاحة.

> ليست كل الوظائف مختبرة على اتصال واتساب حقيقي. اختبر الميزات والصلاحيات في مجموعة تجريبية قبل الاعتماد عليها، ولا تفترض أن الفلترة تفهم السياق أو تمنع كل الصيغ.

## 🚀 التشغيل

يتطلب المشروع Node.js وnpm واتصالاً بالإنترنت للتثبيت والربط. استخدم بيئة تشغيل حديثة متوافقة مع تبعيات المشروع؛ راجع [`package.json`](package.json) وملفات الإعداد قبل التشغيل.

```bash
node bootstrap/index.mjs
```

المشغّل يحاول إعداد التبعيات والأدوات المطلوبة عند الحاجة. احتفظ بنسخة احتياطية خاصة من بياناتك قبل التحديث؛ لا تحذف `dist/` أو ملفات الجلسات وبيانات البوت. تختلف المتطلبات الفعلية للوسائط والخدمات الخارجية حسب البيئة.

### الاستخدام

1. شغّل البوت وافتح محادثته في تيليجرام.
2. من **ربط واتساب**، اربط الحساب بـ QR أو رمز الاقتران.
3. افتح الويب آب من البوت واضبط المجموعة أو الميزة المطلوبة.
4. فعّل صلاحيات المشرف عند استخدام الحذف أو أدوات إدارة المجموعة، واختبرها أولاً في مجموعة تجريبية.

## 🧪 الاختبارات

لتشغيل عينة من اختبارات الوحدات المرتبطة بالفلترة والمعالجة:

```bash
node --test tests/unit/profanity-filter.test.mjs tests/unit/group-moderation.test.mjs tests/unit/message-cutoff.test.mjs
```

الاختبارات الآلية لا تُغني عن تجربة واتساب وتيليجرام الفعليين. توجد اختبارات أخرى في `tests/`؛ قد يحتاج بعضها إعدادات أو خدمات خارجية. المزيد في [دليل الاختبار](docs/TESTING.md).

## 🛡️ الخصوصية والأمان

- احتفظ بتوكنات Telegram وGitHub ومفاتيح الخدمات وجلسات واتساب خارج المستودع العام، ولا تضعها في البلاغات أو لقطات الشاشة.
- إذا انكشف مفتاح أو توكن في مستودع عام أو محادثة غير آمنة، ألغِه واستبدله من الخدمة المعنية. تشفير مفتاح داخل الكود مع وجود طريقة فكّه لا يجعله سرياً.
- الأوامر التي أُرسلت بالفعل أو المهام الجارية لا يمكن ضمان إلغائها عند إيقاف المعالجة.
- اطّلع على [سياسة الأمان](SECURITY.md) قبل الإبلاغ عن مشكلة أمنية.

## English

**WhatsApp Bot Pro** is an independent WhatsApp management bot controlled through Telegram, with an Arabic web interface for group tools, automated replies, message controls, games, and status publishing. It is not affiliated with WhatsApp or Telegram.

Start with `node bootstrap/index.mjs`. Some features require admin privileges, external services, or real-account verification; see the Arabic documentation above for limitations and safety notes. Please keep credentials and session files private.

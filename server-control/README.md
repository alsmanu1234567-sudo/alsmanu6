# لوحة السيرفر المستقلة

ينسخ مشغّل bootstrap ملفات الخدمة إلى `server-control` داخل مجلد المكتبات الخارجي (`BOT_EXTERNAL_DEPS_DIR` أو `../bol` بالنسبة لمجلد البوت). لا تستخدم الخدمة ملفات البوت من ذلك المجلد بعد التشغيل، لكنها تحتاج Node.js ونفق HTTPS واتصال الإنترنت واستمرار حاوية الاستضافة.

من محادثة المطور الخاصة: لوحة المطور ← لوحة السيرفر المستقلة، أو `/serverlink 120` لإنشاء رابط لمدة 120 دقيقة. يقبل الأمر من 1 إلى 10080 دقيقة. يمكن إيقاف الرابط من تيليجرام أو اللوحة. تنتهي العملية مع انتهاء المدة؛ ويتوقف الرابط أيضاً إذا أوقفت الاستضافة الحاوية، أو تعطّل النفق، أو نفدت موارد النظام. إصدار رابط جديد يلغي الجلسة السابقة إذا أمكن الوصول إليها.

الرابط يمنح حامله تنفيذ الأوامر بصلاحيات حساب تشغيل البوت. لا تشاركه، ولا تضعه في سجل أو صورة. الحذف في مدير الملفات للملفات والمجلدات الفارغة فقط، وتُحظر مسارات الجلسات والاعتماد المعروفة في المدير المرئي، لكن الشِل غير مقيد ويمكنه تجاوز تلك الحماية. هذا ليس بديلاً عن حساب مستقل أو SSH أو مصادقة متعددة العوامل.

عند تشغيل البوت من bootstrap يحتفظ المشغّل بآخر 1 MiB تقريباً من مخرجات البوت في ملف `bot.log` داخل مجلد لوحة السيرفر بقراءة خاصة. قد يتضمن السجل رسائل أو أرقاماً أو توكنات؛ لا تشاركه بلا مراجعة. السجل يبدأ بعد تثبيت هذا الإصدار وإعادة تشغيله. خدمة النفق خارجية، وقد يتغير الرابط إذا انقطع النفق. معاينة الملفات النصية الكبيرة تعرض نهاية الملف للقراءة فقط؛ الملفات الثنائية المدعومة للمعاينة هي صور JPEG وPNG وWebP وGIF حتى 3MB.

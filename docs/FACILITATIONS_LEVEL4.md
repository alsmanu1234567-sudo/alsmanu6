# تسهيلات المستوى 4 — إعدادات عامة تسري على كل البوت (v8.8.0)

ما قبل هذا المستوى كان داخل «الردود» و«المجموعات». هذا المستوى **يعمّ البوت**: مفاتيح واحدة تتحكم
بكل الردود، بحث واحد يغطي كل شيء، ولوحة صحة تخبرك بحالة النظام الآن.

## ١ · إعدادات عامة (`services/general-settings.mjs`)

تُحفظ لكل حساب في `bot-data/general-settings/<hash>.json` بصلاحية `0600`.

| الإعداد | المدى | الأثر |
| --- | --- | --- |
| `defaultFooter` | ≤ 60 حرفاً | يُستخدم كتذييل لأي رسالة أزرار/بطاقات لا تملك تذييلاً |
| `defaultImageRef` | صورة من معرض الحساب | تُرسل مع أي رد بلا صورة (نصي أو أزرار) |
| `dailyGlobalLimit` | 0 = بلا حد | سقف يومي لكل الردود معاً، يُعاد ضبطه كل يوم |
| `pausedUntil` | ≤ 30 يوماً | نافذة الإيقاف الطارئ |

- الصورة تُتحقق عبر `normalizeImageRef` فلا تخرج عن مجلد صاحب الحساب.
- التذييل الافتراضي **لا يكتب فوق** تذييل مكتوب يدوياً: الأولوية لما كتبته في الرد نفسه.

## ٢ · إيقاف طارئ للردود (Kill switch)

- أزرار جاهزة: **30 دقيقة · ساعة · 3 ساعات · 12 ساعة · يوم** + «▶ استئناف الآن».
- أثناء الإيقاف: `runAutoReplies` يخرج فوراً قبل أي مطابقة — يعني لا ردود تلقائية إطلاقاً،
  بينما **حماية المجموعات تبقى تعمل** (الحذف والتحذيرات مستقلة).
- يعود تلقائياً عند انتهاء المدة (الفحص زمني، لا يحتاج مؤقتاً شغّالاً).
- النص يوضح المتبقي: «الردود متوقفة مؤقتاً — باقي 1 ساعة و30 دقيقة».

## ٣ · بحث شامل في البوت

بحث واحد يجمع في نتيجة مرتّبة:

1. **الردود التلقائية** — بالمفتاح أو المحتوى أو المجلد أو النوع.
2. **حماية المجموعات** — كلمات ممنوعة، دومينات محظورة/مسموحة، نصوص تحذير وترحيب، قوائم كلمات جاهزة.
3. **القوالب الجاهزة** — بالاسم أو الوصف.
4. **الإعدادات العامة** — التذييل، الصورة، الحد اليومي.

- حد أدنى حرفان، وحد أقصى 8 نتائج لكل قسم، و40 نتيجة إجمالاً (حتى تبقى اللوحة سريعة).
- `GET /api/fw/search?q=…` → `{query, total, groups:[{kind,label,items}], index}`.

## ٤ · صحة النظام

بطاقة تعرض مباشرة: عدد جلسات واتساب المتصلة · الأرقام النشطة من الإجمالي · الردود المفعّلة من الإجمالي ·
مدة التشغيل · استهلاك الذاكرة · إصدار Node. مزوّد الصحة يُحقن من `dist/index.mjs` (حيث السوكِتات)،
ويُقرأ عبر `GET /api/fw/general`.

## ٥ · توسيع قائمة الكلمات الممنوعة

- القائمة الشديدة صارت **227 مدخلاً** (كانت 152) بثلاثة أقسام جديدة:
  7) صيغ إضافية للسب الجنسي (لهجات وتراكيب) · 8) ألفاظ جنسية صريحة ومحتوى إباحي · 9) إنجليزية إضافية.
- لا تكرار: الاختبار يتحقق أن كل سطر فريد، وأن صيغ `~` (كلمة مستقلة) تحمي الكلمات النظيفة مثل
  «كسر» و«توكيل/تكنيك» و«كلاسيك».

## الواجهة

كل ما سبق في لوحة واحدة: **الردود التلقائية → 🧩 عام**:

1. حالة الإيقاف وأزرار المدد.
2. التذييل والصورة الافتراضية والحد اليومي + عدد المستخدم اليوم.
3. صندوق البحث الشامل بنتائج مباشرة أثناء الكتابة.
4. بطاقة صحة النظام.

## المسارات

```
GET  /api/fw/general                    → {settings, pause, usedToday, presetMinutes, health, replyStats}
POST /api/fw/general                    → {defaultFooter, defaultImageRef, dailyGlobalLimit}
POST /api/fw/general/pause              → {minutes}  (0 = استئناف)
GET  /api/fw/search?q=…                 → نتائج البحث الشامل
```

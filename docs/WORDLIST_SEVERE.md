## كيف يُشغَّل؟

من لوحة الحماية: **إعدادات المجموعة → الكلمات الممنوعة → 🚫 قوائم جاهزة من البوت** → علّم على
«شديدة جداً — سب الأعراض + جنس». بمجرد التعليم:

1. تُضاف القائمة إلى فلتر المجموعة،
2. ويُشغَّل **فلتر الكلمات** تلقائياً (بدون خطوة ثانية)،
3. ويظهر عدد الكلمات الفعّالة بالأعلى.

القيود الحالية محفوظة: كلماتك الخاصة تبقى كما هي وتُدمج مع القائمة بلا تكرار.

## صيغة الملف (قابلة للتعديل يدوياً)

```
كلمة            → تُمنع إذا ظهرت داخل أي نص (مطابقة جزئية)
~كلمة           → تُمنع فقط إذا جاءت كلمة مستقلة
كلمة اخرى       → عبارة من كلمتين أو أكثر
# ...           → تعليق
```

**لماذا `~`؟** لأن المطابقة الجزئية للكلمات القصيرة تُنشئ أخطاء مزعجة: «كس» موجودة داخل «كسر» و«بوكس»،
و«نيك» داخل «تكنيك»، و«اير» داخل «ايران». لذلك تُكتب الجذور القصيرة بـ `~` فتُطابق الكلمة المستقلة فقط،
بينما الصيغ الطويلة (كسمك، شرموطة، منيوك…) تُطابق جزئياً بلا مشاكل.

**التطبيع التلقائي:** التشكيل والتطويل و(أ إ آ → ا) و(ى → ي) و(ة → ه) و(ؤ→و) و(ئ→ي) تُزال قبل المطابقة،
فلا حاجة لتكرار كل صيغة إملائية، ولا يمكن التهرب بكتابة «كُسْـمك» أو «كسـمـك».

## الواجهة البرمجية

```
GET  /api/fw/groups/guard/words/presets?groupId=…   → القوائم + المختار + إحصاء الكلمات
POST /api/fw/groups/guard/words/preset               {groupId, presetId:"severe", enable:true|false}
```

- معرّفات غير معروفة تُرفض ولا تُخزَّن (`normalizePresetKeys`).
- الاختيار يُخزَّن في إعداد المجموعة كـ `wordPresets: ["severe"]` (مصفوفة معرّفات فقط، بلا نسخة من الكلمات).

## إضافة قائمة جديدة

1. أنشئ ملفاً في `data/wordlists/` بنفس الصيغة.
2. أضفه إلى `PRESETS` في `services/wordlist-presets.mjs`:
   `{id: 'name', name: 'الاسم الظاهر', file: 'name.txt', description: '…'}`.
3. يظهر تلقائياً في الواجهة وفي `GET …/words/presets`.

# المستوى 1 — نسخ إعدادات المستخدمين احتياطياً (مركز المطوّر + GitHub)

**الإصدار:** 8.3.0 · **الحالة:** المستوى 1 مكتمل ومُختبَر

---

## 1) ما الذي يُرفع بالضبط؟

| القسم | المحتوى |
|---|---|
| `replies` | الردود التلقائية (المُشغِّل/الرد/التفعيل/الوسوم) |
| `messages` | إعدادات قسم الرسائل: `msgSettings`, القوالب `msgTemplates`, الردود السريعة `quickReplies` |
| `ai` | `aiSystemPrompt`, `aiTemperature`, `aiMaxTokens`, `aiBlacklist`, `nvidiaModel` |
| `myMsgs` | إعدادات «قسم رسائلي» لكل ملف رقم — **بلا أرقام**: تُخزَّن كشرائح `slot` بالترتيب فقط |
| `groupGuard` | أعلام الحماية، النصوص، القوائم (كلمات/دومينات)، ساعات التقرير — لكل مجموعة |

## 2) ما الذي **لا** يُرفع أبداً (بيانات شخصية/أسرار)

- جلسات واتساب و`creds.json` وأي شيء يخص الربط.
- أرقام الهواتف، `telegramChatId`، الاسم/المعرّف، `referralCode`.
- مفاتيح الـAPI (مثل `nvidiaKey`)، التوكنات، كلمات المرور، `session`، `creds`، OTP/PIN.
- قوائم الأعضاء، القائمة البيضاء (أرقام أعضاء)، التحذيرات، قوائم الطرد، سجلّات الرسائل/الحالات.

طبقتان للحماية:
1. **قائمة سماح صريحة** للحقول المسموح تصديرها.
2. **`scrub()`** يحذف أي مفتاح يطابق `api key|token|secret|password|session|creds|auth|otp|pin|cookie` + المفاتيح الشخصية، ويحدّ العمق والحجم ويمنع `__proto__`.

## 3) من أين أستخدمها؟

### أ) مركز المطوّر
`/developer-console` ← تبويب **🗄 نسخ إعدادات المستخدمين**:
- اختر الأقسام (خمسة مربعات اختيار).
- **⬇ إنشاء نسخة وتنزيلها** → ملف JSON باسم `settings-YYYYMMDD-HHMM.json`.
- **⬆ استعادة من ملف** → اختيار ملف ثم دمج آمن (لا يحذف شيئاً).

### ب) عبر GitHub (نفس التبويب + بطاقة داخل تبويب GitHub)
1. اختر **المستودع** (من مستودعات حساب التوكن) و**الفرع**.
2. اضبط **مسار الملف** (افتراضي `backups/settings-....json`).
3. **⬆ رفع إلى GitHub** — ينشئ/يحدّث الملف مع `sha` تلقائياً.
4. **📁 عرض النسخ المحفوظة** — يجلب قائمة ملفات `backups/` من المستودع لتختار واحداً.
5. **⬇ جلب من GitHub واستعادة** — ينزّل، يفكّ base64، يتحقق من الصيغة، ثم يستعيد (نمط `merge` أو `replace`).

## 4) واجهات الـAPI (كلها بجلسة المطوّر فقط)

```
GET  /api/developer/backup/overview
POST /api/developer/backup/snapshot        { areas }
POST /api/developer/backup/restore         { snapshot, mode, areas }
GET  /api/developer/backup/github/repos
POST /api/developer/backup/github/push     { repo, path, branch, areas, message }
POST /api/developer/backup/github/pull     { repo, path, branch, mode, areas, restore }
GET  /api/developer/backup/github/list     ?repo=&dir=backups&branch=
```

## 5) الأمان والحدود
- الجلسة قصيرة (15 دقيقة) والتوكن في `#hash` لا يُرسل للسجلات.
- لا يمكن الكتابة خارج مستودع يملكه التوكن؛ المسارات مرفوضة إن احتوت `..`.
- حد حجم النسخة: **800KB** (وGitHub 900KB) — رسالة عربية واضحة عند التجاوز.
- الاستعادة الافتراضية **دمج** ولا تنشئ أرقاماً ولا تلمس الجلسات؛ تُتخطى الحسابات غير الموجودة.

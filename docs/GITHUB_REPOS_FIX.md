# إصلاح «اختر المستودع» لا يعرض قائمة المستودعات (v8.11.0)

## الأسباب التي عولجت
1. **مسار ملف الإعدادات**: التوكن يُحفظ مشفّراً في `config.json`، والدالة القديمة كانت تبحث عنه في
   `BOT_ROOT` فقط. عند التشغيل من `bootstrap/` يختلف مجلد العمل → الملف غير موجود → التوكن فارغ
   → القائمة فارغة بلا رسالة. الآن نجرّب 8 مسارات معروفة.
2. **تحميل التوكن مرة واحدة عند الإقلاع**: صار يُقرأ عند الطلب (`_ghLoadToken`) من `GITHUB_TOKEN`
   أو من الملف المشفّر.
3. **طلب واحد بلا بدائل**: `/user/repos` وحدها. الآن:
   - `/user/repos?affiliation=owner,collaborator,organization_member` (حتى 5 صفحات)
   - `/installation/repositories` لتوكنات GitHub App
   - `/users/{login}/repos` كاحتياط
   - كاش 60 ثانية + `?refresh=1` لجلب جديد.
4. **رسائل خطأ مفهومة**: 401 = توكن غير صالح · 403/صلاحيات = فعّل `Metadata: Read` واختر المستودعات ·
   rate-limit = انتظر دقائق.

## ما تراه في اللوحة الآن
- قائمة المستودعات في **صفحة النسخ** و**النسخ التلقائي المجدول** (نفس القائمة) مع عدد المستودعات
  وعدد الخاص منها، وزر **🔄 تحديث القائمة**.
- عند الفشل تظهر **السبب** مكان القائمة بدل فراغ.
- `GET /api/developer/github/status` يعطي: existence/kind للتوكن، الحساب، عدد المستودعات، أول خطأ.

## إن ظلّت القائمة فارغة
1. من البوت: **GitHub → 🔑 تغيير التوكن** وأعد إدخال توكن جديد.
2. في GitHub → Settings → Developer settings → Tokens: تأكد أن التوكن يملك
   **Metadata: Read** (و`Contents: Read and write` للرفع) وأن **Repository access** يشمل مستودعاتك.
3. تأكد أن الحساب يملك مستودعاً واحداً على الأقل.

## إصلاح إضافي في نفس النسخة
- تغيير/حذف التوكن يمسح كاش المستودعات فوراً (كان يعرض قائمة التوكن القديم بعد التغيير).

## v8.11.1 — التوكن يُدخل من «خيارات المطور → GitHub → 🔑 تغيير التوكن»
1. التوكن يُحفظ الآن في **مكانين**: `config.json` و`bot-data/github-token.enc` (0600)، ويُقرأ من
   أولهما المتاح. السبب: `config.json` يُعاد كتابته من أقسام أخرى فيضيع المفتاح — ومع حارس الذاكرة
   (إعادة تشغيل على 512MB) كان التوكن يضيع بعد كل إعادة تشغيل.
2. رسالة الحفظ تعرض: الحساب + **عدد المستودعات المرئية**، أو سبب الرفض.
3. زر **🩺 تشخيص GitHub** (تيليجرام) يعرض: التوكن (موجود/نوعه)، الحساب، مسار ملف الإعدادات وهل موجود،
   عدد المستودعات وأسماء أول 5، والسبب العربي للفشل.
